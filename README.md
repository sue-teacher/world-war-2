# 지수쌤과 함께하는 제2차 세계대전 탐험

중학교 2학년 세계사 수업용 인터랙티브 학습 웹앱입니다. 학생은 세계 지도(OpenStreetMap) 위에서
제2차 세계대전의 주요 사건을 순서대로 따라가며 배우고, 사건의 순서를 맞춰보고, 복습 문제로 확인합니다.

## 학습 흐름

1. **지도 학습** — 세계 지도 위 번호 핀을 따라 8개 주요 사건을 시간 순서대로 학습
2. **순서 맞추기** — 뒤섞인 사건에 올바른 순번(번호 선택)을 지정해 전쟁의 흐름 완성
3. **복습 문제** — 객관식·OX 문제로 핵심 내용 점검 후 결과·별점 확인

## 다루는 주요 사건 (시간 순)

| 순서 | 연도 | 사건 | 장소 |
| --- | --- | --- | --- |
| 1 | 1939 | 독일의 폴란드 침공 (전쟁 발발) | 바르샤바 |
| 2 | 1940 | 독일의 파리 점령 | 파리 |
| 3 | 1940 | 영국 점령 실패(영국 본토 항공전) | 런던 |
| 4 | 1941 | 일본의 진주만 공습(미국 참전) | 하와이 진주만 |
| 5 | 1943 | 스탈린그라드 전투(전환점) | 스탈린그라드 |
| 6 | 1944 | 노르망디 상륙작전 | 노르망디 |
| 7 | 1945 | 독일의 항복(유럽 전쟁 종료) | 베를린 |
| 8 | 1945 | 원자폭탄 투하와 일본 항복(종전) | 히로시마 |

> 교과서 표현에 맞추어 '됭케르크 철수' 대신 **파리 점령**과 **영국 점령 실패**를 중심으로 구성했습니다.

## 기술

- 순수 HTML / CSS / JavaScript (빌드 도구·프레임워크 없음)
- 지도: [Leaflet](https://leafletjs.com/) + OpenStreetMap 타일 (지도 표시에는 인터넷 연결 필요)
- 디자인: `ui-ux-pro-max` 방법론 기반 토큰화된 다크 테마 (색/간격/반경/그림자 CSS 변수)
- 정적 사이트로 어떤 호스팅에도 그대로 배포 가능

## 로컬에서 실행

빌드가 필요 없습니다. `index.html`을 브라우저로 열거나 간단한 정적 서버를 사용하세요.

```bash
# 예: Python 내장 서버
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 뼈대 (상단 진행바, 무대, 토스트) |
| `styles.css` | 디자인 시스템 토큰 + 전 화면 스타일 (다크 테마) |
| `data.js` | 8개 사건 학습 콘텐츠 · 순서 퀴즈 · 복습 문제 |
| `maps.js` | Leaflet(OSM) 세계 지도 + 번호 핀 구성 |
| `app.js` | 화면 라우팅, 학습/순서/복습 로직, 점수·진행도 |

## 배포

정적 파일이므로 Vercel에서 별도 빌드 설정 없이 배포됩니다. `vercel.json`은 `cleanUrls`만 지정합니다.

## 접근성

- 모든 상호작용 요소에 보이는 포커스 링 제공
- 정답/오답을 색뿐 아니라 아이콘(✅/❌)·텍스트로 함께 표시
- 지도 핀·버튼에 접근성 이름(aria-label/title) 부여
- `prefers-reduced-motion` 존중
